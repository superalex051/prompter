# Contributing

Contributions are welcome. Open an issue first if the change is big, so we can agree on it before you spend time.

By submitting a contribution (a pull request, a patch or code in an issue), you agree that:

1. You license it under the GNU General Public License version 3, like the rest of the project.
2. You also grant Florida Focus Creation LLC the right to distribute it under other terms. This is needed to ship the App Store build of Prompter.

If you do not agree to both, please open an issue to describe the idea instead of sending code.

Before you send a change, read the build and test steps in the [README](README.md) and run `scripts/test.sh`.
