# M9. Markdown support (iPhone, Mac, Presenter view)

The owner's decisions: a "Markdown formatting" switch in `PrompterSettings` (tolerant decoding, default on; scripts without Markdown
are unaffected), and bold renders in the scheme's amber cue colour on the teleprompter (the text is already Heavy).

## Design
- **Parser** (`Core/Text/MarkdownInline.swift`, `ScriptMarkdown.swift`): our own, one line at a time, because the Mac editor needs
  the source position of every marker and styled stretch, and both apps must agree. CommonMark's delimiter-run algorithm for
  `*`/`_` (flanking, intraword `_`, rule of 3), `~~` exactly two, code spans, links/images (text only), backslash escapes.
  Unmatched markers show as typed. A test checks it against Foundation's `AttributedString(markdown:)`.
- **Blocks:** `#`…`######` + space → `ScriptLineKind.heading(level:)`; `---`/`***`/`___` → `.rule`; `- `/`* `/`+ ` → "• ";
  `1. ` kept as written; `> ` stripped. `// notes` and `[pause N]` win (checked first in `ScriptMarkup.kind`).
- **Document:** `PrompterDocument(body:markdown:)` shows text without markers, with inline runs per paragraph. Headings and
  rules are their own kinds, so they hold no spoken words (like notes): not counted, not timed (the WPM pace is spread over the
  text lines only), not followed by voice; they scroll past at the reading pace.
- **Look** (`PrompterText`): bold = cue colour at the paragraph's opacity; italic = italic of the same weight; strike = struck
  and half opacity; code plain; headings 1.2× / 1.1× / 1.0× in amber; rules a centred dim line of box-drawing characters.
- **Counts:** `ReadingStats(text:markdown:)` = `PrompterDocument(...).timedWordCount`. Library, editors, engine, voice all use it.
- **Live switching:** iPhone `PrompterController.showMarkdown(_:)` (called from the canvas update) rebuilds the document and the
  voice aligner; Mac `PresenterSession.settingsChanged()` rebuilds its document.
- **Editors:** Mac editor highlights live (bold amber, italic, struck, headings bigger, markers dimmed). iPhone editor stays plain
  text; its tip mentions Markdown when the setting is on.
- **Import:** `.md`, `.markdown` (+ `.mdown`, `.mkd`, `.mkdn` by extension), kept as source text, title from the file name.
- **Settings/help:** switch in iPhone Settings → Text (also in the prompter's popover), Mac Settings → Text and the Presenter
  settings panel; How to use on both gets a Markdown section (`MarkdownHelp`).
- **Screenshots:** `-demoData -script markdown` adds `DemoData.markdownScript` and opens it (existing demo scripts unchanged).
